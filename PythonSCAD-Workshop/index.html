01

立方体を作成する

課題

はじめに、一辺60 mmの立方体を作ります。どのようなコードを書けばよいか考えてみましょう。

ヒント：以下のコードの続きを考えてみよう 
from pythonscad import *

# 一辺60 mmの立方体を作成
box = ???

show(box)

立方体を作る命令は cube([Xの長さ, Yの長さ, Zの長さ]) です。今回作りたいのは一辺が60mmなので、X・Y・Zすべてに同じ数字を入れます。

目標のカタチ

Python 
from pythonscad import *

# 一辺60 mmの立方体を作成
box = cube([60, 60, 60])

# 画面に表示
show(box)

コードの意味

cube([60, 60, 60])

cube()は直方体を作る命令です。
角かっこの中は、次の順番で大きさを指定します。

[X方向の長さ, Y方向の長さ, Z方向の長さ]

今回はすべて60 mmなので、立方体になります。

やってみよう！

cube([60, 30, 20]) のように、X, Y, Z の数字をバラバラにして実行してみよう！立方体以外のどんな形（直方体）になるか観察してみよう。

02

立方体の位置を合わせる

課題

先ほどの立方体は、角が原点に置かれています。立方体の「中心」を原点に合わせるようにコードを変更してみましょう。

ヒント：かっこの中にオプションを追加しよう 
from pythonscad import *

# 中心を原点に合わせて立方体を作成
box = cube(
    [60, 60, 60],
    ???
)

show(box)

かっこの中に center=True という「オプション」をカンマ区切りで書き足すだけで、中心が原点に合います。

目標のカタチ

Python 
from pythonscad import *

# 中心を原点に合わせて立方体を作成
box = cube(
    [60, 60, 60],
    center=True
)

show(box)

正解は center=True を追加することでした！
立方体の中心を原点にすると、各面の位置は次のようになります。

X軸
右の面：X = 30
左の面：X = -30
Y軸
奥の面：Y = 30
手前の面：Y = -30
Z軸
上の面：Z = 30
下の面：Z = -30

一辺が60 mmなので、中心から各面までの距離は半分の30 mmです。

やってみよう！

center=False に変更したり、このオプション自体を消したりして、立方体の位置がどう変わるか（元の位置に戻るか）確認してみよう。

03

球を作成する

課題

次に、サイコロの目を作るための「球」を作成します。直径16 mmの球を作ってみましょう。

ヒント：球を作る命令を書こう 
from pythonscad import *

# 直径16 mmの球を作成
ball = ???

show(ball)

球を作る命令は sphere(r=半径, fn=64) です。「直径」が16 mmのとき、「半径（r）」はいくつになるでしょうか？

目標のカタチ

Python 
from pythonscad import *

# 直径16 mm、半径8 mmの球を作成
ball = sphere(
    r=8,
    fn=64
)

show(ball)

コードの意味

sphere(r=8)

sphere()は球を作る命令です。rは半径を表します。

直径16 mm ÷ 2 = 半径8 mm

fn=64について

fn=64

球の表面を滑らかにするための設定です。数字を大きくすると滑らかになりますが、コンピュータの計算量も増えます。

やってみよう！

滑らかさを決める fn=64 の数字を、fn=10 のように小さくしたり、逆に fn=100 にしたりしてみよう。球の表面のカクカク具合がどう変化するか観察してみよう！

04

球の位置を合わせる

課題

立方体の上面は、原点からZ方向に30 mmの位置にあります。作成した球が立方体の上面に乗るように、移動させてみましょう。

ヒント：移動量を足し算しよう 
from pythonscad import *

# 球を作成
ball = sphere(r=8, fn=64)

# 球をZ方向に30 mm移動
ball = ball + ???

show(ball)

図形を移動させるには、元の図形に [Xの移動量, Yの移動量, Zの移動量] を足します。今回はZ方向（上）にだけ30mm動かします。

目標のカタチ

Python 
from pythonscad import *

# 球を作成
ball = sphere(
    r=8,
    fn=64
)

# 球をZ方向に30 mm移動
ball = ball + [0, 0, 30]

show(ball)

移動量は次の順番で指定します：

[X方向, Y方向, Z方向]

今回の移動は [0, 0, 30] なので、X方向とY方向には動かさず、Z方向に30 mm移動します。
これにより、球の中心が立方体の上面に置かれます。

やってみよう！

[30, 0, 30] や [0, -30, 30] のように、XやYの移動量も変更してみよう。球が右や手前にどう動くか確認してみよう。

05

立方体から球をくりぬく

課題

最後に、重なった2つの図形を使って、立方体から球を「引き算」し、サイコロの目（くぼみ）を完成させましょう！

ヒント：図形の引き算をしよう 
from pythonscad import *

# (立方体:box と 球:ball の作成は省略)

# 球を立方体の上面に移動
ball = ball + [0, 0, 30]

# 立方体から球をくりぬく
dice = ???

show(dice)

図形の引き算は、普通の計算と同じように -（マイナス）の記号を使います。立方体から球を引きましょう。

目標のカタチ

Python 
from pythonscad import *

# 一辺60 mmの立方体
box = cube(
    [60, 60, 60],
    center=True
)

# 直径16 mmの球
ball = sphere(
    r=8,
    fn=64
)

# 球を立方体の上面に移動
ball = ball + [0, 0, 30]

# 立方体から球をくりぬく
dice = box - ball

# 完成した形を表示
show(dice)

引き算による形状の加工

dice = box - ball

このコードでは、立方体から球と重なっている部分を取り除いています。

立方体 − 球 ＝ 球状のくぼみがある立方体

球の中心を立方体の表面に置いているため、くぼみは半球状になり、深さは球の半径と同じ8 mmになります。

やってみよう！

引き算の順番を逆にして ball - box にするとどうなるでしょうか？どんな形になるか予想してから、実際に試してみましょう！

FINAL SOURCE

完成コード

ここまでの内容をまとめ、寸法を変数として定義し直した、より美しいコードです。

dice_step1.py 
from pythonscad import *

# ==========================================
# 寸法
# ==========================================
DICE_SIZE = 60
PIP_DIAMETER = 16
PIP_RADIUS = PIP_DIAMETER / 2

# ==========================================
# 立方体を作成
# ==========================================
box = cube(
    [DICE_SIZE, DICE_SIZE, DICE_SIZE],
    center=True
)

# ==========================================
# 球を作成
# ==========================================
ball = sphere(
    r=PIP_RADIUS,
    fn=64
)

# ==========================================
# 球を立方体の上面に移動
# ==========================================
ball = ball + [0, 0, DICE_SIZE / 2]

# ==========================================
# 立方体から球をくりぬく
# ==========================================
dice = box - ball

# ==========================================
# 表示
# ==========================================
show(dice)
